Automated launch mode

An ordinary app cannot reliably keep launching after it backgrounds itself. The bundled instrumentation runner uses Android's test automation channel to execute each action, capture am start -W and focused-window output, press Back, and continue automatically.

adb shell am instrument -w -r -e launch true -e delayMs 750 io.github.specters312.intentlab/.IntentFuzzInstrumentation

Resolution-only instrumentation is the same command without -e launch true. Launch mode covers the generic action corpus. Device-derived deep links are enumerated automatically but are not batch-launched.

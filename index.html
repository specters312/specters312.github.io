Can a hyperlink force fastboot?

No—not on a correctly secured Android build. A normal webpage can request an exported Settings activity after a user tap, but it cannot silently reboot the device. Rebooting requires Android's privileged android.permission.REBOOT, which is unavailable to ordinary browsers and third-party apps. If USB debugging is already authorized, use ADB.

adb reboot bootloader
adb reboot fastboot
adb reboot recovery
